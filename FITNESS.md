# VigoraPulse - Fitness Tracking App

A full-stack fitness tracking web application built with React and Flask, designed to help users track and manage their fitness journey

## Tech Stack

- Frontend: React, CSS
- Backend: Flask (Python)
- Database: SQLite

## Features

User authentication — secure Login and Signup with hashed passwords
Protected routes — pages are inaccessible without logging in
Landing page dashboard
Navigation bar with dynamic logout button
Help & Contact page
404 error page
Sign out functionality
