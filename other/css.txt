width: 18px; height: 18px; — fixes the image to a small 18x18 square
margin-left: 18px; — pushes it 18px from the left
opacity: 0.35 — makes it 65% transparent, so it looks faded/subtle
filter: invert(1) — this flips all the colors of the image. Black becomes white, white becomes black. 1 means 100% inverted. This is commonly used to make dark icons work on dark backgrounds.
flex-shrink: 0 — prevents the image from shrinking if the container gets too small. Since the parent is likely display: flex, without this the image could squish.

A better way of moving elelments without using padding is using flex
display: flex -- on parent
position: absolute -- on child
adding positioning using top, left, right, transform ect --- in child
